Terruño Wine | Sistema de Gestión Integral de Bodega
Terruño Wine es una aplicación de escritorio diseñada para la administración eficiente y privada de un local de bebidas y bodega. Este proyecto nació como una solución personalizada para optimizar el control de stock, el registro de egresos y la visualización del rendimiento neto en tiempo real.

🍷 Propósito del Proyecto
El objetivo principal es proporcionar una herramienta robusta y offline que permita a los propietarios gestionar su negocio sin depender de servicios en la nube, garantizando la privacidad total de los datos financieros y de inventario.

🚀 Características Principales
Panel de Rendimiento: Visualización dinámica de la facturación bruta, egresos y balance neto diario, semanal, mensual y anual.

Gestión de Inventario Local: Control total sobre precios de costo, precios de venta y niveles de stock con alertas de reposición críticas.  

Registro de Ventas Multicanal: Interfaz rápida para anotar ventas manuales especificando métodos de pago como Efectivo, Tarjeta de Débito, Crédito y Mercado Pago.

Caja de Egresos: Módulo dedicado para el seguimiento de pagos a proveedores, servicios (luz, alquiler), sueldos y reposición de mercadería.

Análisis de Datos: Gráficos estadísticos sobre las formas de pago preferidas y ranking de productos con mayor y menor rotación.

🛠️ Stack Tecnológico
Frontend: React con Tailwind CSS para una interfaz moderna, intuitiva y elegante.  

Entorno de Escritorio: Electron.js para la creación de un ejecutable local (.exe).

Base de Datos: SQLite para la persistencia de datos local, asegurando integridad y rapidez sin necesidad de internet.

Visualización: Recharts para la generación de gráficos de rendimiento y tendencias.

🔧 Instalación y Uso
Clonar el repositorio: git clone [https://github.com/MaxiGestro/terruno-wine.git](https://github.com/MaxiGestro/terruno-wine.git)

Instalar dependencias: npm install

Ejecutar en modo desarrollo: npm run electron:serve

Generar instalador (.exe): npm run build:win
